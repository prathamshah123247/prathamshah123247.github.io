# Pratham Shah Portfolio — Astro

Responsive static portfolio rebuilt with Astro, TypeScript, CSS and GSAP.

## Local development

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## GitHub Pages

The repository includes a GitHub Actions workflow at `.github/workflows/deploy.yml` that builds Astro and deploys `dist/` to GitHub Pages on pushes to `main`.

In GitHub: **Settings → Pages → Source → GitHub Actions**.
